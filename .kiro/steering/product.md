# Product principles — The Lost Memory Club

- Build an original, short, polished psychological horror game for Kiroween 2026.
- Target one complete 5–8 minute playthrough, not a large open world.
- Core Memory Loop: find a VHS tape, discover a clue, unlock Snake, win, change the environment, and reveal an ending.
- Position the entry as Resurrection by **reinventing functional analog media interactions**, not by merely decorating a game with VHS imagery.
- All source code, comments, project documentation, UI text and submission materials must be in clear English. Team discussion may be in Spanish.
- Avoid copyrighted third-party characters, songs, screenshots or film footage. Record all external asset licenses.
- Accessibility: keyboard-operable controls and a reduced-distortion option must be included in the completed MVP.
- Do not claim an unimplemented feature works; distinguish planned, prototype and tested functionality.
